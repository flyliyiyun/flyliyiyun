## How I build with coding agents

I treat coding agents as collaborators inside a controlled delivery loop:

`problem framing -> written constraints -> architecture review -> bounded implementation -> tests -> browser verification -> deployment rehearsal -> documented decisions`

The agent can generate code quickly. My role is to define the problem, make trade-offs explicit, reject unsafe or incorrect output, preserve domain constraints, and require evidence before calling work complete.

Read the detailed FSSQ case study: [How I delivered a full-stack product with coding agents](https://github.com/flyliyiyun/fssq/blob/main/docs/case-study-coding-agent-delivery.md).
